# Spec Delta

## ADDED Requirements

### Requirement: A use carries its line
Every name a connector records as used SHALL come with the line of the node that makes the use, counted from 1: in the uses of a declaration, in the uses of the code that runs as the file loads, and in the members read on a value of unknown class. A name used on several lines SHALL keep the first. The graph SHALL keep the line beside the name and hand out both.

#### Scenario: A use keeps the line of the file that holds it
- **WHEN** `a.ts` uses `foo` at line 3 and `b.ts` uses `foo` at line 9, and the load of `b.ts` uses `bar` at line 12
- **THEN** the graph lists `foo` at line 3 for `a.ts`, `foo` at line 9 for `b.ts` and `bar` at line 12 for its load

### Requirement: The layout moves with the facts
When the archived facts change shape, the layout number of the snapshot and the format of the fact keys SHALL change in the same commit, so that a snapshot or a fact cache written before is never read as the new shape.

#### Scenario: A snapshot of the layout before the lines of uses is not loaded
- **WHEN** the snapshot on disk carries layout number 14, the last before a use had a line
- **THEN** loading returns no index

#### Scenario: A snapshot of the layout before the lines of uses is rebuilt
- **WHEN** the snapshot on disk carries layout number 14 and the repository is refreshed
- **THEN** the refresh builds the index again from the files
- **AND** the snapshot on disk is replaced by one of the current layout

### Requirement: Generated files are tagged
The engine SHALL tag a file as generated when a comment among its first ten lines says a tool wrote it, when a `linguist-generated` rule of a `.gitattributes` names it, or when its name or directory is one that only tools use. It SHALL prefer a miss to a false positive: a comment that denies it, a file that is the template of generated files and a mention in code tag nothing.

#### Scenario: A header marker tags a file
- **WHEN** one file starts with `// Code generated by protoc-gen-go. DO NOT EDIT.`, another has `This code was generated by Amplication.` on a line of its first block comment, and a third has `// @generated` on its second line
- **THEN** each is tagged as generated

#### Scenario: A comment that denies or only mentions it tags nothing
- **WHEN** a file says `// This file is not auto-generated.`, one says `// these queries are automatically generated as hooks by codegen`, one holds the text `do not edit this` in a string, one has `@generated` after its tenth line, and `seed.template.ts` says it was auto-generated by a tool
- **THEN** none is tagged as generated

#### Scenario: A gitattributes rule tags the files it names
- **WHEN** `.gitattributes` has `*.min.js linguist-generated` and `docs/api/** linguist-generated=true`, and `docs/.gitattributes` has `keep.md -linguist-generated`
- **THEN** `dist/a.min.js` and `docs/api/a.md` are tagged as generated, and `docs/api/keep.md` and `src/a.js` are not

#### Scenario: A rule that is edited out is gone at the next refresh
- **WHEN** `.gitattributes` names `named.txt` as generated, the file is indexed, and only `.gitattributes` is edited to name nothing
- **THEN** the next refresh rebuilds the index and `named.txt` is no longer tagged as generated
- **AND** a file tagged by a header marker or by its name keeps its tag

#### Scenario: A name or directory only tools use tags a file
- **WHEN** the files are `src/__generated__/types.ts`, `src/api.generated.ts`, `pkg/x.pb.go`, `svc/x_pb2.py` and `lib/x.g.dart`, and `src/generated.ts`, `src/generated/helper.ts` and `pkg/pb.go`
- **THEN** the first five are tagged as generated and the last three are not
